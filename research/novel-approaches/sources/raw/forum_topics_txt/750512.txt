# Clarification request: public API-generated datasets, Kaggle Benchmarks proxy data, and §2.5 / §2.8
url: https://www.kaggle.com/competitions/name-that-llm/discussion/750512
author: Lucky Raj date: 2026-10-18 votes: {'totalVotes': 2, 'canUpvote': True, 'totalUpvotes': 2}
Hi, and thank you for hosting. Section 6 (External Data and Tools) is clear about public, free data. Several participants are unsure how it interacts with the model providers' own terms, so a short written answer would help everyone plan on equal terms.

Public API-generated datasets. Is a public, free Kaggle dataset of passages generated by the 18 candidate models through their official APIs permitted External Data under §2.6.a without further approval? An example is prvsiyan/prvsiyans-extended-name-that-llm-dataset, licensed CC BY 4.0.
Provider output terms. Several providers' terms restrict using outputs to develop "competing" models. Does the host consider training a non-generative 18-way attribution classifier on such passages to be consistent with those terms? Or must each participant clear this with the providers themselves?
Kaggle Benchmarks Model Proxy. Is text generated with the free Kaggle Benchmarks Model Proxy quota permitted as training data for this competition? May it be shared publicly as a Kaggle dataset? (The same question is open in /discussion/750038.)
Winner obligations. If such data are used, does §2.5.a.3 ("input data or pretrained models with an incompatible license") also cover the trained model weights, or only the data? And what should the §2.8 documentation include about the provenance and attribution of external data?
Thank you!
